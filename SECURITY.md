# Security policy

bunvex is pre-alpha and not meant for production yet; security reports are still very welcome.

**Please do not open a public issue for a vulnerability.** Report it privately through GitHub:
[Report a vulnerability](https://github.com/bunvex/bunvex/security/advisories/new) (Security → Advisories).
We aim to acknowledge a report within 7 days and will keep you updated until it is resolved.

Only the latest version on `main` receives security fixes during the pre-alpha phase.
