# bunvex

The package an app installs: bunvex/server, bunvex/values, bunvex/browser, bunvex/react, and the bunvex CLI.

**Status:** `bunvex/server`, `bunvex/values`, `bunvex/browser` (`@bunvex/client`), `bunvex/react` (`@bunvex/react`,
with `react` as an optional peer, as Convex's) and the `bunvex` command are wired; `bunvex/nextjs`,
`bunvex/react-clerk` and `bunvex/react-auth0` follow their packages. What will live here, and its status, is
tracked in [ARCHITECTURE.md](../../ARCHITECTURE.md):

- re-exports only; bin: bunvex
